# AssetDataInsightSuite 講義(基礎から)

ゲームアセットの品質を**継続的に**見るツールの、**考え方・コード・アルゴリズム・専門用語**を、順に学ぶ講義です。各回は「**ゴール → 説明と実行できる例 → 確認問題 → 解答 → まとめ**」で、コードは実際に動かして確かめてあります(`tests/test_docs.py` が、ずれと出力を検査します)。

| 回 | 題 | 学ぶこと | 目安 |
|---|---|---|---|
| [0](00-introduction.md) | 継続的に見る | 設計の軸(**単一のパイプライン・データモデル**)・4 テーブル・**追記専用** | 1.5 h |
| [1](01-ingest.md) | 取り込み | `Protocol` + `@register` の**プラグイン**・`since` の差分・**失敗を履歴に残す** | 3 h |
| [2](02-rules.md) | ルールと不具合 | **YAML + `evaluate`**・動的 import・ライフサイクル・**解消は再評価した所だけ**・`module` の危険 | 3.5 h |
| [3](03-trend.md) | 集計 | 線形補間のパーセンタイル・**z スコアと IQR**・前回との差(集合)・推移と再発 | 3.5 h |
| [4](04-output-testing-capstone.md) | 出力・GUI・テスト | **終了コード**・マニフェスト・バックグラウンドのジョブ・**新しいルールを足す** | 半日 |

## 進め方

- **前提**: Python の基本。SQL の `SELECT` / `JOIN`・平均と標準偏差は、その回で必要な分を説明します。
- 例は、リポジトリのルートで動かします(`.venv` の Python)。ネットワークは使いません。DB は**メモリ**か一時ファイル。
- 講義のあとの既知の問題は [学習資料](../learn/index.md)。
